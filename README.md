## Selected projects

### [Nexus-Core](https://github.com/markmikma/nexus-core)

An operations-focused homelab platform for WSL2/Linux. It brings together application deployment, service health checks, rollback, audit events, Prometheus/Grafana monitoring, access control, and backup validation in one inspectable environment.

**What it demonstrates:** how I approach application operations: make service state visible, automate safe repeatable actions, keep an audit trail, and plan for recovery.

### [SysPulse CLI](https://github.com/markmikma/syspulse-cli)

A small Python CLI for checking CPU, memory, and disk usage and summarising `ERROR` and `WARNING` entries from logs. It is container-ready and intentionally simple enough to be useful as an operations support utility.

**What it demonstrates:** basic Linux/WSL monitoring, log triage, Python scripting, and clean repository practices.
